# Prior art

## Webrecorder

Use browser-based and standalone Desktop versions of [ARCHIVE WEBPAGE]
and [REPLAY WEBPAGE] from the [Webrecorder] project.
They provide interactive browser-based web archiving, and interactive
exploration and replay.

On macOS/Homebrew, just type:
```shell
brew install --cask archivewebpage
brew install --cask replaywebpage
```

## PANDAS 4

[PANDAS 4] is the fourth generation of the National Library of Australia’s web
archiving workflow system. It provides curators with tools for website selection,
collection building, scheduled crawling, and quality assurance using web crawlers
such as Heritrix, Browsertrix, and HTTrack.

## Hister

[Hister] is a private search engine for the pages you visit and the files you keep.
It indexes their full contents so you can find information again.
